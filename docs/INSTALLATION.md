# Установка

## Установка одной командой

Установите OWBM одной командой:

```bash
wget -qO- https://raw.githubusercontent.com/dizzety/OWBM-OpenWrt-Backup-Restore-Manager/main/install.sh | sh
```

Затем откройте меню:

```bash
owbm menu
```

Для загрузки установщика уже должен быть установлен `wget`. Установщик проверит наличие Python 3.9 или новее и SSH-клиента. Если их не хватает, он предложит установить их через менеджер пакетов системы. Перед установкой нужно подтвердить действие; для системных пакетов может потребоваться пароль `sudo` или `doas`. В NixOS зависимости устанавливаются в пользовательский профиль Nix, без изменения конфигурации системы.

Автоматическая установка зависимостей поддерживается на NixOS, Debian 11+, Ubuntu 22.04+, Fedora 34+, актуальном Arch Linux и Alpine 3.15+. Для автоматической установки нужен Python 3.9 или новее из репозитория дистрибутива. На других системах установщик продолжит работу, если Python и OpenSSH уже установлены; иначе он остановится, не меняя систему. Сам OWBM устанавливается в `~/.local/bin`; если эта папка не входит в `PATH`, запускайте `~/.local/bin/owbm menu`.

Установщик проверяет SHA-256 и запуск загруженного файла до замены установленной версии. Он меняет только пакеты управляющего компьютера и файл OWBM в домашней папке; к роутеру он не подключается и его настройки не меняет.

Для шифрования резервных копий можно отдельно установить `age` или `gpg`. Это необязательные программы; обычная установка OWBM их не устанавливает.

## Ручная установка

Если Python 3.9+ и OpenSSH уже установлены, файл программы можно скачать отдельно:

```bash
wget -O owbm.pyz https://github.com/dizzety/OWBM-OpenWrt-Backup-Restore-Manager/releases/latest/download/owbm.pyz
wget -O owbm.pyz.sha256 https://github.com/dizzety/OWBM-OpenWrt-Backup-Restore-Manager/releases/latest/download/owbm.pyz.sha256
sha256sum -c owbm.pyz.sha256
python3 owbm.pyz menu
```
